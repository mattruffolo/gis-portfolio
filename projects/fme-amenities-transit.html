Amenities & Transit Extraction for Brochure Maps

An automated FME workflow that turns a site address into a design-ready, layered KMZ of nearby amenities and transit — replacing a manual build for every listing.

Objective

Amenities maps are a standard element of CBRE marketing brochures, and each one was being assembled by hand: find the site, pull nearby retail and services, add transit lines, export, then hand off to the Creative & Design team for styling. The goal was to automate everything up to the design step — one workflow that takes a site address and returns a clean, editable KMZ.

Data

  • Site list — Excel input with property name, address, latitude and longitude.
  • ChainXY — retail and amenity point data, filtered to major categories.
  • Transit — route and station shapefiles for the relevant transit agencies.

Method

  1. Input data — Excel reader for the site list, plus readers for the ChainXY amenity set and transit shapefiles.
  2. Reprojection & data preparation — brought all sources onto a common projection and standardised the attribute schema so downstream joins wouldn't break on field mismatches.
  3. Site buffering — generated a catchment around each site to define "nearby."
  4. Amenity selection — clipped amenities to the catchment and filtered to the major categories brokers actually want on a brochure, rather than every point in the dataset.
  5. Transit extraction — selected the route segments and stations intersecting the catchment.
  6. Categorisation & styling — grouped amenities into display categories and wrote style attributes so the output opens already organised into folders.
  7. KMZ output — exported a single layered KMZ per site, structured so the design team can restyle without rebuilding anything.

Outcome & takeaway

What was a manual per-listing build is now a repeatable run: change the input row, re-run, get a consistent output. The bigger win is consistency — every brochure map now uses the same categories and the same catchment logic, so outputs don't vary by whoever built them. Adding a new city or a new amenity category is a reader change, not a rebuild.
