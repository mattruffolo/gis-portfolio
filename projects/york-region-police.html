York Region Police Response Coverage

A drive-time coverage analysis identifying where response targets aren't met across York Region, quantified by population and ranked by municipality.

Tools ArcGIS Pro Streamlit Python GitHub HTML
Skills Demographic Analysis Spatial Analysis Emergency Coverage Modeling Open Data Integration Open-Source Application Deployment
TypeCoverage analysis
GeographyYork Region, Ontario
OutputCustom Web App

Objective

York Regional Police operate out of 12 police stations located across a region that mixes dense urban centres with large low-density areas. The question this project answers: which parts of the region fall outside target drive-time coverage, how many residents live there, and which municipalities have the best and worst coverage?

Data & Sources

  • York Region Open Data — Police stations and municipal boundaries
  • ArcGIS Pro — Isochrone creation and dissemniation area demographic enrichment.
  • Streamlit — Hosts and displays the interactive map.

Click the image to launch the live application

Outcome & takeaway

The application highlights coverage gaps at a glance and quantifies their impact in population terms rather than geographic area, providing decision-makers with a clearer understanding of where residents are underserved.
