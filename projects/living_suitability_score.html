Living Suitability Site Scoring Analysis

A site suitability analysis evaluating residential living areas across Metro Vancouver. The project used a weighted scoring model to identify and rank locations based on 9 demographic, lifestyle, and access factors.

Tools ArcGIS Pro Overpass Turbo
Skills Weighted Suitibility Modelling Cartographic Design Spatial Data Visualization Demographic Enrichment
TypeSite Scoring and Selection
GeographyMetro Vancouver
OutputStatic Map

Objective

Amenity maps are a standard element of CBRE marketing brochures, and each one was being assembled by hand. The goal was to automate everything up to the design stage by creating a workflow that takes a site address and generates a clean, editable KMZ output.

Data & Sources

  • Metro Vancouver Open Data — Demographic data.
  • Overpass Turbo — Major amenities like cafes, fitness centres, shopping centres, and Park.

Insert static map here.

Outcome

The analysis translated multiple variables into a single site score, allowing locations to be compared consistently across the metropolitan area. By combining several factors into a weighted suitability model, the project provided a data-driven framework for identifying areas with high living suitability.
